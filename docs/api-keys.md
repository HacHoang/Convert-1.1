# API keys

Open the navigation drawer and select the key icon to manage API keys. Choose OpenAI / ChatGPT, Anthropic / Claude, Google / Gemini, or **Nhà cung cấp khác** and enter a provider name. Keys can be added, assigned a name, selected as that provider's default, copied, renamed, and deleted. The list only displays the final five characters of a key.

The manager stores keys locally in this browser or app installation's IndexedDB. Keys are not encrypted and are excluded from app backups. Anyone with access to the device profile may be able to read them; do not save keys on a shared device.

Provider selection in the manager only organizes saved credentials. The existing **Dịch bằng Gemini AI** feature currently uses the selected Google / Gemini key. OpenAI, Claude, and custom-provider keys are stored for management only and are not used by translation yet.
